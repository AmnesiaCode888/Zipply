# Стандарты чистого кода и безопасность (Zipply Code Standards)

## Принципы разработки:
1. **Минимальные изменения (Surgical edits)**: Не трогай несвязанный код, не форматируй весь файл целиком и не удаляй существующие комментарии без явной необходимости.
2. **Безопасные команды**: Никогда не запускай деструктивные команды (`rm -rf /`, `git reset --hard`, `del /s /q`) без предупреждения пользователя.
3. **Обработка ошибок**: Всегда оборачивай асинхронные вызовы и операции ввода/вывода в `try/catch` с понятными диагностическими сообщениями.
4. **Строгая типизация**: Соблюдай строгую типизацию TypeScript, избегай необоснованного использования типа `any`. Создавай четкие интерфейсы и типы.
5. **Самодокументируемый код**: Имена функций и переменных должны четко отражать их назначение без необходимости писать очевидные комментарии.
