# Систематическая 4-фазная отладка (Systematic Debugging)

Главное правило профессионального инженера: **Никогда не пытайся исправлять код, пока не доказал первопричину бага.** Случайные правки («а вдруг заработает?») лишь маскируют проблему и вносят новые регрессии.

## Фаза 1: Точное воспроизведение (Reproduce)
1. Выясни входные данные, при которых возникает сбой.
2. Запусти соответствующий тест или команду: `npm test` / `npx tsx scripts/test-x.ts`.
3. Убедись, что ошибка стабильно воспроизводится.

## Фаза 2: Изоляция первопричины (Root Cause Isolation)
1. Прочти полный стек вызовов (Stack Trace) снизу вверх.
2. Найди первую строку, принадлежащую коду проекта (а не сторонним модулям node_modules).
3. Прочитай этот участок через `file(action="read", start_line=..., end_line=...)`.
4. Сформулируй проверяемую гипотезу: *«Переменная X приходит как undefined, потому что в строке Y отсутствует await»*.
5. При необходимости добавь временный лог или напиши минимальный падающий модульный тест.

## Фаза 3: Минимальный точечный фикс (Surgical Fix)
1. Внеси только те изменения, которые напрямую устраняют изолированную причину.
2. Используй хирургический `file(action="edit")` с блоками SEARCH/REPLACE.
3. Не делай сопутствующего глобального рефакторинга в процессе фикса бага — это усложняет проверку.

## Фаза 4: Верификация доказательствами (Evidence Before Assertion)
1. Запусти повторно команду тестирования / сборки.
2. Убедись, что тест **зеленый**, а ошибка исчезла.
3. Проверь, что фикс не сломал соседние тесты проекта.
4. Только после получения фактического вывода рапортуй об успешном решении.
