# Инструкции по продвинутой работе с Git

## 1. Проверка состояния:
Перед началом любых изменений всегда проверяй текущий статус репозитория:
`git status` и текущую активную ветку: `git branch --show-current`.

## 2. Оформление коммитов (Conventional Commits):
- `feat: добавление нового функционала`
- `fix: исправление ошибки`
- `refactor: изменение структуры без изменения поведения`
- `test: добавление или исправление тестов`
- `docs: обновление документации`

## 3. Разрешение конфликтов слияния:
1. Найди файлы с маркерами конфликтов: `grep_search(query="<<<<<<<")`.
2. Внимательно сравни ветку пользователя и входящие изменения:
   - `<<<<<<< HEAD` — текущие локальные изменения.
   - `=======` — разделитель.
   - `>>>>>>> branch_name` — входящие изменения.
3. Отредактируй файл хирургически через `file(action="edit")`, удалив маркеры конфликта и оставив корректный компилируемый код.
4. Добавь разрешенные файлы в индекс: `git add <file>`.

## 4. Безопасный откат:
- Для отката изменений одного файла: `git checkout HEAD -- <file>`.
- Для отмены индексации: `git restore --staged <file>`.
