# Мастерство работы с инструментом `terminal`

Терминал исполняется в среде **PowerShell (UTF-8)** в Windows.

## 1. Специфика синтаксиса PowerShell:
- **Массивы**: Задавай массивы как `@(elem1, elem2)`, а НЕ `[elem1, elem2]`.
- **Переменные окружения**: Задавай через `$env:NODE_ENV="development"`.
- **Цепочки команд**: Используй точку с запятой `;`. Операторы `&&` поддерживаются только в новых версиях PowerShell Core, поэтому безопаснее использовать `;` или конструкцию `cmd1; if ($?) { cmd2 }`.
- **Вывод строк**: Используй `Select-Object -First N` вместо bash `head -n N`.

## 2. Неинтерактивность (Строгий инвариант)
- НИКОГДА не запускай команды, требующие подтверждения пользователя в stdin без ключей авто-подтверждения!
- Всегда передавай флаги: `npm install -y`, `npx --yes`, `git commit -m "..."`.
- Если команда повиснет в ожидании ввода пользователя — шаг завершится по таймауту с ошибкой.

## 3. Фоновые процессы и серверы (`start_background`)
- Серверы разработки (`npm run dev`, `vite`, `watchers`, демоны) запускаются с параметром `action="start_background"`.
- Обычный вызов `execute` будет ждать завершения процесса и упадет по таймауту.

## 4. Чтение вкладок терминала IDE (`read_terminal`)
- Ты видишь реальные вкладки терминала, открытые пользователем в Zipply!
- Если пользователь пишет: *"Посмотри, что упало в терминале"* или *"Сервер работает?"*:
  1. Вызови `terminal(action="list_terminals")` — просмотр всех запущенных вкладок (PID, статус, CWD).
  2. Вызови `terminal(action="read_terminal", session_id="active")` (или укажи конкретный ID) — для чтения свежего вывода и ошибок.

## 5. Интерактивный ввод (`send_input`)
- Если в фоновом терминале запущен интерактивный процесс (CLI утилита, отладчик, подтверждение), используй `terminal(action="send_input", session_id="...", input="y\n")`.
