# Мастерство долговременной памяти (`manage_memory`)

Долговременная память сохраняется между сессиями диалога и позволяет агенту всегда помнить важные архитектурные решения, запреты и предпочтения пользователя.

## 1. Когда нужно сохранять память:
1. Пользователь выразил стойкое предпочтение (*«Всегда пиши код на TypeScript без any»*, *«Используй pnpm вместо npm»*).
2. Зафиксировано ключевое архитектурное решение проекта (*«В качестве базы используем SQLite в app.db»*).
3. Пользователь рассказал о себе или специфике проекта.

## 2. Операции с памятью:
- **Сохранение факта с указанием темы (Subject-based upsert)**:
  ```json
  manage_memory({
    "action": "add",
    "content": "В проекте используется pnpm v9; npm запускать запрещено",
    "category": "project_fact",
    "subject": "package_manager",
    "importance": 5,
    "tags": ["build", "pnpm"]
  })
  ```
- Если факт с таким же `subject` уже существует, система автоматически обновит его, предотвращая появление противоречащих дубликатов!

## 3. Поиск по памяти:
- `search_memory(query="пакетный менеджер")` — семантический поиск по сохраненным фактам.
- Не захламляй память тривиальными сиюминутными данными — сохраняй только то, что имеет ценность для будущих сессий.
