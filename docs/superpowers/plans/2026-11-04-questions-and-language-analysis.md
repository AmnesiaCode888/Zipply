# Уточнения и анализ языков

**Цель:** дать агенту возможность задавать вопрос с вариантами и продолжать работу после ответа, а также расширить семантический анализ кода.

**Подход:** отдельный инструмент с ожидающим IPC-запросом, привязанным к чату и отмене; существующий анализ TypeScript расширяется, Python подключается через комплектуемый анализатор. Интерфейс следует AGENTS.md.

- [ ] Реализовать вопрос, передачу ответа, отмену и отображение в нужном чате; проверить изоляцию запросов.
- [ ] Добавить анализ Python и сохранить существующее поведение TS/JS; проверить реальные определения, ссылки и ошибки, отмену и границы проекта.
- [ ] Улучшить операции анализа TS/JS, не выполняя незапрошенные изменения файлов.
- [ ] Проверить сборку, тесты и интерфейс; явно сообщить об ограничениях.
