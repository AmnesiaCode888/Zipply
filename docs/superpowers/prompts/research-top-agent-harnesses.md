# Короткий промпт для исследования agent harnesses

> Исследуй, как сильные agent harnesses — Hermes, OpenClaw, Codex, Claude Code, OpenCode, Gemini CLI и Pi — решают мою задачу: **[ЧТО МЕНЯ НЕ УСТРАИВАЕТ И ЧТО ХОЧУ УЛУЧШИТЬ]**. Раздай независимые системы субагентам. Используй актуальные официальные документы, исходники и релизы; отделяй факты от выводов, указывай версии и ссылки. Сравни с **[ПРОЕКТ / КОД]** и дай конкретные пробелы, применимый дизайн, риски, этапы и критерии приёмки. До плана ничего не меняй.
