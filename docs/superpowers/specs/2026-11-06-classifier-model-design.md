# Модель-классификатор — дизайн

## Назначение

Дать пользователю отдельную настройку недорогой модели для классификации и коротких проверок, например `liquid/d1.1`, и упростить вызов этой модели из кода проверок.

## Цели и границы

- Сохранять ID модели отдельно от основной модели и передавать его в конфигурацию агента.
- Предоставить один явный non-streaming вызов классификатора через общий API-клиент.
- Переиспользовать текущие API-ключ и Base URL.
- Пустое поле означает, что модель-классификатор не настроена; вызов helper в этом случае возвращает понятную ошибку.
- Не задавать классификатору автоматические проверки и не менять обычный поток ответа агента.

## Рассмотренные подходы

1. Добавить отдельный ID модели и явный helper вызова. Это сохраняет различие ролей и позволяет проверкам явно выбирать классификатор. **Выбранный подход**.
2. Переиспользовать поле быстрой модели. Это не требует новой настройки, но смешивает краткие ответы и классификацию в одной роли.
3. Сразу переключить существующие проверки на новую модель. В проекте нет заданного контракта результата классификации для таких проверок, поэтому поведение было бы не определено.

Подход выбран исполнителем по просьбе пользователя подготовить готовое изменение без дополнительного согласования.

## Ограничения

- ID совместим с текущим OpenAI-совместимым провайдером и его Base URL.
- Параметр модели независим от основной модели; отдельные ключ и провайдер не вводятся.
- Изменённый интерфейс соблюдает правила `AGENTS.md`: контролы без обводки, теней и свечения; округлённые формы и тёмные поверхности.

## Решение для реализации

Добавить `classifierModel` в `AppSettings`, пустое значение по умолчанию и поле в настройках «Модель и API» с примером `liquid/d1.1`. Передавать значение через `toChatConfig` в `ChatConfig`. Добавить `ChatService.classify(config, messages, options)`: он выбирает `config.classifierModel`, отправляет обычный запрос без стрима и инструментов, ограничивает ответ заданным лимитом (по умолчанию 256 токенов) и возвращает `ChatResponse`.
